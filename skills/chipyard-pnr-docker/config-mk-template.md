# ORFS Configuration Template for Docker Execution
# ================================================

# This file shows the complete config.mk structure for running ORFS
# inside Docker containers with volume mounts.

## Overview

**Execution Mode:** Docker
**Container:** `openroad/orfs:latest`
**PDK:** sky130hd
**Design:** ChipTop (TinyRocket)

## Volume Mount Strategy

The config.mk references paths that are accessible inside the Docker container.
When the parent skill mounts files into the container, the paths change:

| Host Path | Container Path | File |
|-----------|---------------|------|
| `$WORK_DIR/pnr/` | `/workdir/` | config.mk, constraint.sdc |
| `$WORK_DIR/${CONFIG}_nosram.v` | `/nosram.v` | Consolidated nosram Verilog |
| `$WORK_DIR/sram_override.v` | `/sram_override.v` | SRAM override modules |
| `$ORFS_FLOW_PATH/platforms/sky130ram/` | `/OpenROAD-flow-scripts/flow/platforms/sky130ram/` | SRAM macro LEF/LIB/GDS |

## Complete config.mk Template

```makefile
# ==============================================================================
# ORFS Configuration for ChipTop (TinyRocket) — Docker Execution
# ==============================================================================
# Generated by chip-agent:chipyard-pnr-docker
# Execution mode: Docker (openroad/orfs:latest container)
# ==============================================================================

# ------------------------------------------------------------------------------
# DESIGN IDENTIFICATION
# ------------------------------------------------------------------------------
export DESIGN_NAME = ChipTop
export DESIGN_NICKNAME = tinyRocket
export PLATFORM = sky130hd

# ------------------------------------------------------------------------------
# VERILOG SOURCE FILES (Docker paths)
# ------------------------------------------------------------------------------
# All paths are relative to container mount point at /OpenROAD-flow-scripts/flow
# Files mounted from host:
#   /nosram.v — consolidated nosram Verilog (from $WORK_DIR/${CONFIG}_nosram.v)
#   /sram_override.v — SRAM override modules (from $WORK_DIR/sram_override.v)
#
# SRAM macro behavioral .v files — accessed from container's platform directory

export VERILOG_FILES = \
    /nosram.v \
    /sram_override.v \
    /OpenROAD-flow-scripts/flow/platforms/sky130ram/sky130_sram_1rw1r_64x256_8/sky130_sram_1rw1r_64x256_8.v \
    /OpenROAD-flow-scripts/flow/platforms/sky130ram/sky130_sram_1rw1r_44x64_8/sky130_sram_1rw1r_44x64_8.v

# Note: These .v files provide behavioral models for Yosys synthesis
# The actual physical macro LEF/LIB/GDS are provided separately via ADDITIONAL_* macros

# ------------------------------------------------------------------------------
# TIMING CONSTRAINTS (Docker paths)
# ------------------------------------------------------------------------------
export SDC_FILE = /workdir/constraint.sdc

# SDC file is mounted from: $WORK_DIR/pnr/constraint.sdc

# ------------------------------------------------------------------------------
# SRAM MACRO CONFIGURATION (Docker paths)
# ------------------------------------------------------------------------------
# Blackbox SRAM macros during Yosys synthesis (leave as abstract blocks)
export SYNTH_BLACKBOXES = sky130_sram_1rw1r_64x256_8 sky130_sram_1rw1r_44x64_8

# Additional LEF/LIB/GDS for OpenROAD floorplan/place/route
# These are accessed inside the container from /OpenROAD-flow-scripts/flow/platforms/sky130ram/
export ADDITIONAL_LEFS = \
    /OpenROAD-flow-scripts/flow/platforms/sky130ram/sky130_sram_1rw1r_64x256_8/sky130_sram_1rw1r_64x256_8.lef \
    /OpenROAD-flow-scripts/flow/platforms/sky130ram/sky130_sram_1rw1r_44x64_8/sky130_sram_1rw1r_44x64_8.lef

export ADDITIONAL_LIBS = \
    /OpenROAD-flow-scripts/flow/platforms/sky130ram/sky130_sram_1rw1r_64x256_8/sky130_sram_1rw1r_64x256_8_TT_1p8V_25C.lib \
    /OpenROAD-flow-scripts/flow/platforms/sky130ram/sky130_sram_1rw1r_44x64_8/sky130_sram_1rw1r_44x64_8_TT_1p8V_25C.lib

export ADDITIONAL_GDS = \
    /OpenROAD-flow-scripts/flow/platforms/sky130ram/sky130_sram_1rw1r_64x256_8/sky130_sram_1rw1r_64x256_8.gds \
    /OpenROAD-flow-scripts/flow/platforms/sky130ram/sky130_sram_1rw1r_44x64_8/sky130_sram_1rw1r_44x64_8.gds

# Prevent ABC from mapping to SRAM cells (they are blackboxed)
export DONT_USE_CELLS += sky130_sram_1rw1r_64x256_8 sky130_sram_1rw1r_44x64_8

# ------------------------------------------------------------------------------
# SYNTHESIS OPTIONS
# ------------------------------------------------------------------------------
# Hierarchical synthesis preserves SRAM module boundaries
export SYNTH_HIERARCHICAL = 1
export SYNTH_MINIMUM_KEEP_SIZE = 1000

# ABC optimization strategy
export ABC_AREA = 1

# ------------------------------------------------------------------------------
# PHYSICAL DESIGN PARAMETERS
# ------------------------------------------------------------------------------
# Validated: TinyRocket 50MHz on sky130hd
export CORE_UTILIZATION = 50
export PLACE_DENSITY = 0.65

# Timing-driven and routability-driven placement
export GPL_TIMING_DRIVEN = 1
export GPL_ROUTABILITY_DRIVEN = 1

# Setup slack margin (allows for timing variation)
export SETUP_SLACK_MARGIN = 0.3

# SRAM macro placement constraints
export MACRO_PLACE_HALO = 20 20

# ------------------------------------------------------------------------------
# CTS (Clock Tree Synthesis) OPTIONS
# ------------------------------------------------------------------------------
export CTS_CLUSTER_SIZE = 20
export CTS_CLUSTER_DIAMETER = 50

# ------------------------------------------------------------------------------
# FINISH OPTIONS
# ------------------------------------------------------------------------------
export TNS_END_PERCENT = 100
export SKIP_ANTENNA_REPAIR_POST_DRT = 1

# ------------------------------------------------------------------------------
# PARALLELISM
# ------------------------------------------------------------------------------
export NUM_CORES = 4

# ------------------------------------------------------------------------------
# POWER ANALYSIS (disabled to avoid PDN via issues with SRAM halo)
# ------------------------------------------------------------------------------
export PWR_NETS_VOLTAGES =
export GND_NETS_VOLTAGES =

# ==============================================================================
# DOCKER EXECUTION NOTES
# ==============================================================================
#
# This config is designed to run inside Docker containers with volume mounts:
#
# Docker Command:
#   docker run --rm \
#     -v $WORK_DIR/pnr:/workdir \
#     -v $WORK_DIR/${CONFIG}_nosram.v:/nosram.v:ro \
#     -v $WORK_DIR/sram_override.v:/sram_override.v:ro \
#     -w /OpenROAD-flow-scripts/flow \
#     openroad/orfs:latest \
#     make DESIGN_CONFIG=/workdir/config.mk \
#          DESIGN_HOME=/workdir \
#          PLATFORM=sky130hd \
#          synth
#
# Path mapping (host → container):
#   $WORK_DIR/pnr/  →  /workdir/
#   $WORK_DIR/${CONFIG}_nosram.v  →  /nosram.v (read-only)
#   $WORK_DIR/sram_override.v  →  /sram_override.v (read-only)
#   $ORFS_FLOW_PATH/  →  /OpenROAD-flow-scripts/flow/
#
# The SRAM macro files (.lef, .lib, .gds) are accessed at container path:
#   /OpenROAD-flow-scripts/flow/platforms/sky130ram/<macro>/
#
# These are NOT mounted from host — they are built into the Docker image
# at /OpenROAD-flow-scripts/flow/platforms/sky130ram/
#
# ==============================================================================

# ==============================================================================
# SRAM MACRO DETAILS
# ==============================================================================
#
# Sky130 SRAM Macros Used:
#
# 1. sky130_sram_1rw1r_64x256_8
#    - Type: Single-port (1RW + 1R)
#    - Depth: 256 words
#    - Width: 64 bits
#    - Mask granularity: 8 bits
#    - Used for: data_arrays_0_ext (depth=4096, width=8)
#    - Tiling: 16 depth tiles (4096/256)
#    - Total instances: 16
#
# 2. sky130_sram_1rw1r_44x64_8
#    - Type: Single-port (1RW + 1R)
#    - Depth: 64 words
#    - Width: 44 bits
#    - Mask granularity: 8 bits
#    - Used for: tag_array_0_ext (depth=64, width=21)
#    - Tiling: Direct match (depth=64 matches macro depth)
#    - Total instances: 1
#
# Total SRAM macros: 17 (16 + 1)
# Total macro cells in design: ~100K
#
# ==============================================================================

# ==============================================================================
# OVERRIDE MODULE REFERENCE
# ==============================================================================
#
# The sram_override.v file contains the following modules that replace
# behavioral SRAM definitions with sky130_sram macro instantiations:
#
# Module: data_arrays_0_ext
#   - Behavioral: 4096x8, mrw port
#   - Macro: sky130_sram_1rw1r_64x256_8
#   - Tiling: 16 depth tiles
#   - Override logic: depth decoding, address translation, data routing
#
# Module: tag_array_0_ext
#   - Behavioral: 64x21, rw port
#   - Macro: sky130_sram_1rw1r_44x64_8
#   - Tiling: direct (no tiling needed)
#   - Override logic: simple direct mapping
#
# ==============================================================================

# ==============================================================================
# EXPECTED OUTPUT FILES
# ==============================================================================
#
# After successful PnR flow, the following files will be generated:
#
# At $WORK_DIR/pnr/orfs_results/results/sky130hd/tinyRocket/base/:
#   - 6_final.gds      — Final GDSII layout (~255 MB)
#   - 6_final.odb      — Final OpenDB database (~540 MB)
#   - 6_final.v        — Final Verilog netlist (~40 MB)
#   - 6_final.spef     — Parasitic extraction (~156 MB)
#   - 6_final.def      — Final DEF file (~241 MB)
#
# At $WORK_DIR/pnr/orfs_results/reports/sky130hd/tinyRocket/base/:
#   - 6_final.rpt      — Final PPA report
#   - 5_2_route.rpt    — Routing DRC report
#   - ... (other stage reports)
#
# At $WORK_DIR/pnr/orfs_results/logs/sky130hd/tinyRocket/base/:
#   - synth.log        — Synthesis log
#   - floorplan.log    — Floorplan log
#   - place.log        — Placement log
#   - cts.log          — CTS log
#   - route.log        — Routing log
#   - finish.log       — Finish log
#
# ==============================================================================
```

## Path Conversion Table

This table shows how paths are converted between local and Docker execution:

| Operation | Local Version | Docker Version |
|-----------|--------------|----------------|
| **config.mk location** | `$WORK_DIR/pnr/config.mk` | `/workdir/config.mk` (mounted) |
| **constraint.sdc** | `$WORK_DIR/pnr/constraint.sdc` | `/workdir/constraint.sdc` (mounted) |
| **nosram Verilog** | `$WORK_DIR/${CONFIG}_nosram.v` | `/nosram.v` (mounted) |
| **SRAM override** | `$WORK_DIR/sram_override.v` | `/sram_override.v` (mounted) |
| **SRAM LEF** | `$ORFS_FLOW_PATH/platforms/sky130ram/<macro>/<macro>.lef` | `/OpenROAD-flow-scripts/flow/platforms/sky130ram/<macro>/<macro>.lef` |
| **SRAM LIB** | `$ORFS_FLOW_PATH/platforms/sky130ram/<macro>/<macro>_TT_1p8V_25C.lib` | `/OpenROAD-flow-scripts/flow/platforms/sky130ram/<macro>/<macro>_TT_1p8V_25C.lib` |
| **SRAM GDS** | `$ORFS_FLOW_PATH/platforms/sky130ram/<macro>/<macro>.gds` | `/OpenROAD-flow-scripts/flow/platforms/sky130ram/<macro>/<macro>.gds` |
| **SRAM behavioral .v** | `$ORFS_FLOW_PATH/platforms/sky130ram/<macro>/<macro>.v` | `/OpenROAD-flow-scripts/flow/platforms/sky130ram/<macro>/<macro>.v` |
| **Results directory** | `$WORK_DIR/pnr/orfs_results/` | `/workdir/orfs_results/` (mounted) |

## Common Configuration Values

### TinyRocketConfig (Default)

| Parameter | Value | Description |
|-----------|-------|-------------|
| `DESIGN_NAME` | `ChipTop` | Top module name |
| `DESIGN_NICKNAME` | `tinyRocket` | Short name for output directories |
| `PLATFORM` | `sky130hd` | SkyWater 130nm HD PDK |
| `CORE_UTILIZATION` | `50` | Standard cell utilization (50%) |
| `PLACE_DENSITY` | `0.65` | Placement density (65%) |
| `GPL_TIMING_DRIVEN` | `1` | Enable timing-driven placement |
| `GPL_ROUTABILITY_DRIVEN` | `1` | Enable routability-driven placement |
| `SETUP_SLACK_MARGIN` | `0.3` | Setup slack margin (0.3ns) |
| `MACRO_PLACE_HALO` | `20 20` | Halo around SRAM macros (20um) |
| `NUM_CORES` | `4` | Number of CPU cores for parallel synthesis |

### Multi-Clock Domains

| Clock | Port | Period | Description |
|-------|------|--------|-------------|
| core_clock | `clock_uncore_clock` | 10ns (100MHz) | Main core clock |
| serial_clock | `serial_tl_clock` | 10ns (100MHz) | Serial link clock |
| jtag_clock | `jtag_TCK` | 100ns (10MHz) | JTAG debug clock |

All three clocks are asynchronous to each other via `set_clock_groups -asynchronous`.

## Troubleshooting

### Common Issues

1. **"No such file or directory" errors in Docker**
   - Check that volume mounts are correct
   - Verify paths in config.mk use container paths, not host paths

2. **SRAM macro LEF/LIB not found**
   - Ensure SRAM macros are present in `/OpenROAD-flow-scripts/flow/platforms/sky130ram/`
   - Check the Docker image has sky130hd PDK installed

3. **Config.mk file not found by ORFS**
   - Verify the volume mount maps `$WORK_DIR/pnr/` to `/workdir/`
   - Ensure `DESIGN_CONFIG=/workdir/config.mk` path is correct

4. **Output files missing after PnR**
   - Check the logs at `/workdir/orfs_results/logs/sky130hd/tinyRocket/base/`
   - Ensure `$WORK_DIR/pnr/orfs_results/` directory is writable

5. **SRAM macro instantiation errors**
   - Verify the sram_override.v has correct module ports
   - Check that the behavioral .v files are included in VERILOG_FILES
