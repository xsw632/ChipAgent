```scala
package chipagent

import chisel3._

class TrivialModule extends Module {
  val io = IO(new Bundle {
    val in  = Input(UInt(8.W))
    val out = Output(UInt(8.W))
  })
  io.out := io.in
}
```

Create `chisel-project/src/main/scala/chipagent/Generate.scala`:
```scala
package chipagent

import chisel3._
import circt.stage.ChiselStage

object Generate extends App {
  val targetDir = if (args.contains("--target-dir")) {
    val idx = args.indexOf("--target-dir")
    args(idx + 1)
  } else {
    "../generated"
  }

  ChiselStage.emitSystemVerilogFile(
    new TrivialModule,
    Array("--target-dir", targetDir),
    Array("-disable-all-randomization", "-strip-debug-info")
  )
}
```

CRITICAL API notes:
- Import `circt.stage.ChiselStage` (NOT `chisel3.stage.ChiselStage`)
- Use `emitSystemVerilogFile` (NOT `emitVerilog` which is deprecated/removed)
- firtoolOpts as third parameter array
- Default target-dir is `../generated` (relative to chisel-project/ CWD)
- When compile.sh passes an absolute path via `--target-dir`, it overrides the default

Create `scripts/compile.sh`:
- Set `#!/usr/bin/env bash` and `set -euo pipefail`
- Resolve PLUGIN_ROOT: use `CLAUDE_PLUGIN_ROOT` env var if set, otherwise derive from script location: `PLUGIN_ROOT="${CLAUDE_PLUGIN_ROOT:-$(cd "$(dirname "$0")/.." && pwd)}"`
- Set `PROJECT_DIR="$PLUGIN_ROOT/chisel-project"`
- Set `OUTPUT_DIR="$PLUGIN_ROOT/generated"`
- Export `SBT_OPTS="-Dsbt.supershell=false"`
- Unset `CHISEL_FIRTOOL_PATH` if set: `unset CHISEL_FIRTOOL_PATH 2>/dev/null || true`
- Create `$OUTPUT_DIR` directory if it does not exist: `mkdir -p "$OUTPUT_DIR"`
- Create a temp file for capturing output: `LOG=$(mktemp)`
- Run compilation with timeout. The sbt command must pass `--target-dir` as an argument to Generate.scala's `args` array. sbt's `runMain` forwards everything after the class name as program arguments:
  ```bash
  cd "$PROJECT_DIR"
  timeout 120 sbt --batch "runMain chipagent.Generate --target-dir $OUTPUT_DIR" > "$LOG" 2>&1
  ```
  Store the exit code: `EXIT_CODE=$?`
- On success (EXIT_CODE=0): check that at least one .sv file exists in `$OUTPUT_DIR`. If found, print "Compilation successful:" followed by `ls "$OUTPUT_DIR"/*.sv`. If no .sv files found despite exit 0, print warning and exit 1.
- On failure (EXIT_CODE != 0, BUILD-03): print "BUILD ERROR:" header with timestamp (`date -Iseconds`), print the captured log content from `$LOG`, print suggestion: "Check chisel-project/build.sbt and source files in chisel-project/src/main/scala/chipagent/", exit with code 1.
- Clean up temp file in a trap: `trap "rm -f $LOG" EXIT`

Create `hooks/hooks.json`:

```json
    {
      "type": "PostToolUse",
      "matcher": {
        "tool": "Write|Edit",
        "path": "*/src/main/scala/**/*.scala"
      },
      "command": "${CLAUDE_PLUGIN_ROOT}/scripts/compile.sh",
      "timeout": 120000
    }
  ]
}
```

CRITICAL hook rules:
- Matcher MUST be narrow: only `src/main/scala/**/*.scala` files
- Do NOT match on `generated/` directory (infinite loop -- see PITFALLS.md Pitfall 5)
- Use `${CLAUDE_PLUGIN_ROOT}` for all paths (not hardcoded)
- 120000ms timeout (120 seconds) for sbt compilation
