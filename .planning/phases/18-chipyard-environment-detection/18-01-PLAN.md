**Section 1: Chipyard detection block -- insert AFTER the Docker detection block (after line 135, before "Compute capability flags")**

```bash
# Detect Chipyard
CHIPYARD_INSTALLED="false"
CHIPYARD_DIR_DETECTED=""
CHIPYARD_CANDIDATES=(
  "${CHIPYARD_DIR:-}"
  "$HOME/chipyard"
  "$HOME/Desktop/chipyard"
  "/opt/chipyard"
)
for candidate in "${CHIPYARD_CANDIDATES[@]}"; do
  if [ -n "$candidate" ] && [ -f "$candidate/build.sbt" ] && [ -d "$candidate/generators/chipyard/src/main/scala" ]; then
    CHIPYARD_INSTALLED="true"
    CHIPYARD_DIR_DETECTED="$candidate"
    break
  fi
done
```

IMPORTANT: Use `build.sbt` as the primary marker (verified on actual Chipyard installation). The secondary check `generators/chipyard/src/main/scala` confirms it is a real Chipyard installation (NOT the empty ~/chipyard directory that only contains .devcontainer/). Do NOT use `generators/src/main/scala` -- that path does NOT exist on real Chipyard installations. Note: `$HOME/Desktop/chipyard` is included as a candidate because it is the actual install location on this machine and is already the default in skills/chipyard-rtl/SKILL.md.

**Section 2: RISCV toolchain detection block -- insert immediately AFTER the Chipyard detection block**

```bash
# Detect RISCV toolchain
RISCV_INSTALLED="false"
RISCV_PATH=""
RISCV_CANDIDATES=(
  "${RISCV:-}"
  "${CHIPYARD_DIR_DETECTED:+$CHIPYARD_DIR_DETECTED/.conda-env/riscv-tools}"
  "${CHIPYARD_DIR_DETECTED:+$CHIPYARD_DIR_DETECTED/riscv-tools}"
  "/opt/riscv"
)
for candidate in "${RISCV_CANDIDATES[@]}"; do
  if [ -n "$candidate" ] && [ -f "$candidate/bin/riscv64-unknown-elf-gcc" ]; then
    RISCV_INSTALLED="true"
    RISCV_PATH="$candidate"
    break
  fi
done
```

IMPORTANT: RISCV detection MUST come after Chipyard detection because some candidates reference `$CHIPYARD_DIR_DETECTED`. Use bash parameter expansion `${CHIPYARD_DIR_DETECTED:+...}` to skip candidates when Chipyard was not found (produces empty string, caught by `[ -n "$candidate" ]`). The `.conda-env/riscv-tools` path is the typical Chipyard conda toolchain location.
