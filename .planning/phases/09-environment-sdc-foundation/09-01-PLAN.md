  <name>Task 2: Create validate-pdk.sh pre-flight validation script</name>
  <files>scripts/validate-pdk.sh</files>
  <action>
Create `scripts/validate-pdk.sh` that validates all required nangate45 PDK files exist before PnR operations.

**Script requirements:**
1. Start with `#!/usr/bin/env bash` and `set -euo pipefail`
2. Source `_common.sh` for PLUGIN_ROOT
3. Read PDK path with fallback chain:
   - First: `$NANGATE45_DIR` env var (allows override for testing)
   - Second: Read from `.chipagent/env.json` via `jq -r '.pdk.nangate45.path // empty'`
   - If neither provides a path, print error telling user to run `/chip-agent:initialize` and exit 1
4. Check these 5 required files exist under the PDK directory:
   - `lib/NangateOpenCellLibrary_typical.lib`
   - `lef/NangateOpenCellLibrary.tech.lef`
   - `lef/NangateOpenCellLibrary.macro.mod.lef`
   - `gds/NangateOpenCellLibrary.gds`
   - `rcx_patterns.rules`
5. For each missing file, print `ERROR: Required PDK file missing: <full_path>`
6. After checking all files, if any were missing, print a summary line and exit 1
7. If all files present, print `PDK validation passed: <pdk_dir>` and exit 0

**Make the script executable:** `chmod +x scripts/validate-pdk.sh`
