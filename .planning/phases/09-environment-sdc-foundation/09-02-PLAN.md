<task type="auto">
  <name>Task 1: Create generate_sdc.sh with sequential/combinational detection</name>
  <files>scripts/generate_sdc.sh</files>
  <action>
Create `scripts/generate_sdc.sh` that takes a module name, analyzes its Verilog, and writes appropriate SDC constraints.

**Script structure:**
1. `#!/usr/bin/env bash` with `set -euo pipefail`
2. Source `_common.sh` for PLUGIN_ROOT
3. Accept `MODULE` as first argument (required). Print usage and exit 1 if missing.
4. Accept optional second argument for project container dir (default: `MyDesign`).

**Locate files:**
- Verilog file: `$PLUGIN_ROOT/$PROJECT_DIR/$MODULE/workspace/generated/$MODULE.v`
- If not found, try `$PLUGIN_ROOT/$PROJECT_DIR/$MODULE/workspace/generated/` and look for any `.v` file (Chisel may emit a different filename). If still not found, exit 1 with clear error.
- spec.json: `$PLUGIN_ROOT/$PROJECT_DIR/$MODULE/workspace/spec.json`
- Output: `$PLUGIN_ROOT/$PROJECT_DIR/$MODULE/workspace/pnr/constraint.sdc`

**Extract module name from Verilog (NEVER from filename):**
```bash
MODULE_NAME=$(grep -m1 '^module ' "$VERILOG_FILE" | sed 's/^module \([A-Za-z_][A-Za-z0-9_]*\).*/\1/')
```
Exit 1 if MODULE_NAME is empty.

**Detect sequential vs combinational (CRITICAL -- do NOT check for clock port):**
Check for actual register usage: `grep -qE 'always @\(posedge' "$VERILOG_FILE"`.
Chisel `Module` always emits clock/reset ports even for combinational logic. Only `always @(posedge` indicates real register usage.

**Read clock period:**
1. If spec.json exists, try `jq -r '.clock_period_ns // empty'`
2. Default: `2.0`

**Create output directory:** `mkdir -p` the pnr directory.

**Write sequential SDC template** (when `always @(posedge` found):
```sdc
current_design MODULE_NAME

set clk_name  core_clock
set clk_port  [get_ports clock]
set clk_period PERIOD

create_clock -name $clk_name -period $clk_period $clk_port

set_input_delay  [expr $clk_period * 0.2] -clock $clk_name [all_inputs]
set_output_delay [expr $clk_period * 0.2] -clock $clk_name [all_outputs]
```
Replace MODULE_NAME and PERIOD with actual values. Note: Using `[all_inputs]` is fine -- `create_clock` on clock port takes precedence over input_delay on it.

**Write combinational SDC template** (no `always @(posedge`):
```sdc
current_design MODULE_NAME

set clk_period PERIOD

create_clock -name virtual_clk -period $clk_period

set_input_delay  0.0 -clock virtual_clk [all_inputs]
set_output_delay 0.0 -clock virtual_clk [all_outputs]
set_max_delay $clk_period -from [all_inputs] -to [all_outputs]
```
Replace MODULE_NAME and PERIOD with actual values.

**Print summary to stdout:**
- Module name, type (sequential/combinational), clock period, output file path

**Make executable:** `chmod +x scripts/generate_sdc.sh`
