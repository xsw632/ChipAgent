  <action>
Replace the entire content of hooks/hooks.json with the official event-keyed format from 03-RESEARCH.md Pattern 4:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "${CLAUDE_PLUGIN_ROOT}/scripts/compile.sh",
            "timeout": 120
          }
        ]
      }
    ]
  }
}
```

Key changes from the legacy format:
1. `hooks` is an OBJECT keyed by event name ("PostToolUse"), not an array.
2. `matcher` is a regex STRING ("Write|Edit"), not an object with tool/path fields.
3. Each matcher group has a nested `hooks` array of handler objects.
4. Handler objects have explicit `"type": "command"`.
5. `timeout` is 120 (SECONDS), not 120000 (milliseconds).
6. Uses `${CLAUDE_PLUGIN_ROOT}` for the script path (HOOK-02).

CRITICAL: Do NOT add a lint hook. Lint is orchestrated by generate.md skill only. Adding a lint PostToolUse hook would risk infinite loops (HOOK-03). The compile hook is the ONLY PostToolUse hook.
