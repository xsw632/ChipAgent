    - parsePower extracts percentage line below Total row (e.g., 53.4%, 45.9%, 0.7%)

  <action>
Add two new exported pure functions to mcp-server/tools/get-report.ts:

1. `parsePower(content: string)` returning `{ total_w: number | null; internal_pct: number | null; switching_pct: number | null; leakage_pct: number | null }`:
   - Match the Total row: `/^Total\s+([\d.e+-]+)\s+([\d.e+-]+)\s+([\d.e+-]+)\s+([\d.e+-]+)/m`
   - Match the percentage line (line after Total, indented): `/^\s+([\d.]+)%\s+([\d.]+)%\s+([\d.]+)%\s*$/m`
   - Return parsed floats or all nulls if Total row not found

2. `parseSynthArea(content: string)` returning `{ synth_area: number | null }`:
   - Match: `/Chip area for module '\\?\w+':\s+([\d.]+)/`
   - Return parsed float or null

Then integrate both into the registerGetReport handler:
- In the `file === "6_finish.rpt"` branch, call `parsePower(content)` and merge result into metrics alongside existing parseFinishReport
- In the `file === "synth_stat.txt"` branch, call `parseSynthArea(content)` and merge result into metrics alongside existing parseSynthStat
