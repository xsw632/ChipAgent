**Pipeline Steps (5 steps):**

**Step 0 -- Verify Prerequisites:**
- Set PLUGIN_ROOT, MODULE from $ARGUMENTS
- Check `MyDesign/$MODULE/workspace/generated/$MODULE.v` exists
- If missing, STOP with message to run `/chip-agent:workflow` first

**Step 1 -- Check Environment:**
- Call `mcp__chipagent-backend__check_environment` with no arguments
- Verify `orfs.installed === true` and `sky130hd.installed === true`
- If either is false, STOP with instructions to install ORFS and sky130hd PDK
- Extract `orfs.flow_path` for use in subsequent steps

**Step 2 -- Generate Config:**
- Read `MyDesign/$MODULE/workspace/spec.json` if it exists, extract `clock_port` (default "clock") and `clock_period_ns` (default 10)
- Call `mcp__chipagent-backend__generate_config` with:
  - module_name: $MODULE
  - verilog_path: absolute path to MyDesign/$MODULE/workspace/generated/$MODULE.v
  - workspace_dir: absolute path to MyDesign/$MODULE/workspace
  - clock_port: from spec.json or "clock"
  - clock_period_ns: from spec.json or 10
- Extract `config_mk`, `design_name` from response

**Step 3 -- Run All 6 Stages Sequentially:**
For each stage in [synth, floorplan, place, cts, route, finish]:
  1. Call `mcp__chipagent-backend__run_stage` with stage, config_mk_path (from Step 2), orfs_flow_path (from Step 1)
  2. If success === false, STOP with error: "STAGE_NAME FAILED. Error: <stderr tail>"
  3. Call `mcp__chipagent-backend__get_report` with design_name (from Step 2), stage, orfs_flow_path (from Step 1)
  4. Present per-stage metrics to user:
     - synth: "Synthesis: <cell_count> cells, <synth_area> um^2"
     - floorplan: "Floorplan: WNS=<wns>ns, TNS=<tns>ns"
     - place: "Placement: WNS=<wns>ns, TNS=<tns>ns"
     - cts: "CTS: WNS=<wns>ns, TNS=<tns>ns"
     - route: "Routing: <violations> DRC violations"
     - finish: "Finish: WNS=<wns>ns, TNS=<tns>ns, Power=<total_w * 1e6>uW, Area=<area>um^2"

**Step 4 -- Format PPA Report:**
- Read the agent definition at `agents/pnr-report-formatter.md` (relative to plugin root) and follow the agent's rules
- Pass the agent these data from the get_report responses accumulated in Step 3:
  - From synth get_report: cell_count, synth_area
  - From finish get_report: wns, tns, total_w, internal_pct, switching_pct, leakage_pct, area, utilization
  - From route get_report: violations
  - Clock name and period from Step 2 (spec.json or defaults)
  - design_name from Step 2
- The agent formats and presents the PPA summary report in conversation

**Key changes:**

1. **Role section:** Update to say it formats PPA metrics from MCP tool responses (not raw files).

2. **Artifact Loading section:** Replace the file-based loading table with a "Metrics Input" section. The agent receives metrics as structured data passed by the skill (from get_report MCP tool responses), NOT from reading files. The skill passes:
   - `cell_count` (from synth get_report)
   - `synth_area` (from synth get_report)
   - `wns`, `tns` (from finish get_report)
   - `total_w`, `internal_pct`, `switching_pct`, `leakage_pct` (from finish get_report)
   - `area`, `utilization` (from finish get_report)
   - `violations` (from route get_report)
   - `clock_name` and `clock_period_ns` (from skill Step 2)
   - `design_name` (from skill Step 2)

3. **Parsing Steps:** Replace file-parsing steps with metric-formatting steps:
   - Step 1: Timing -- Determine PASSED/FAILED from WNS (negative = VIOLATED, >= 0 = MET). Format WNS, TNS, clock info.
   - Step 2: Power -- Convert total_w to microwatts (multiply by 1e6). Compute individual power: internal_uW = total_uW * internal_pct / 100, same for switching and leakage.
   - Step 3: Area -- Format synth_area, post-PnR area with utilization, cell count.
   - Step 4: DRC -- Format violation count (0 = "Clean (0 violations)").
   - Step 5: Artifacts -- List ORFS artifact paths:
     - Netlist: {orfs_flow_path}/results/sky130hd/{design_name}/base/1_2_yosys.v
     - GDS: {orfs_flow_path}/results/sky130hd/{design_name}/base/6_1_merged.gds
     - Reports: {orfs_flow_path}/reports/sky130hd/{design_name}/base/

4. **Report Template:** Keep the exact same format from the existing agent:
```
=== PnR Verification Report: <ModuleName> ===

Timing:     <PASSED|FAILED> (<MET|VIOLATED>)
  WNS:      X.XX ns
  TNS:      X.XX ns
  Clock:    <clock_name> @ <period> ns

Power:
  Internal:    XX.X uW  (XX.X%)
  Switching:   XX.X uW  (XX.X%)
  Leakage:     XX.X uW  (XX.X%)

Area:
  Synthesis:   XXX um^2
  Post-PnR:    XXX um^2 (XX% utilization)
  Cell Count:  XXX

DRC:         Clean (0 violations)

Artifacts:
  Netlist:     <orfs_results>/<design>/base/1_2_yosys.v
  GDS:         <orfs_results>/<design>/base/6_1_merged.gds
  Reports:     <orfs_reports>/<design>/base/
```

5. **Anti-Patterns:** Keep existing ones, add:
   - DO NOT read files from MyDesign/$MODULE/workspace/pnr/reports/ -- metrics come from MCP tool responses
   - DO NOT report power in raw Watts -- always convert to microwatts
