**simulate.sh changes:**

This script currently takes `$1` as module name. With workspace support, use the `/` detection heuristic from research (Pitfall 2): if `$1` contains `/`, treat as workspace path; otherwise treat as v1.0 module name.

After the existing PLUGIN_ROOT resolution block (lines 1-13), replace the hardcoded directory assignments with:

```bash
# --- Workspace-aware path resolution ---
ARG="${1:-}"
if [[ "$ARG" == */* ]]; then
  # Workspace mode: argument is a path like workspace/Foo
  case "$ARG" in
    /*) WORKSPACE_DIR="$ARG" ;;
    *)  WORKSPACE_DIR="$PLUGIN_ROOT/$ARG" ;;
  esac
  MODULE=$(basename "$WORKSPACE_DIR")
  GENERATED_DIR="$WORKSPACE_DIR/generated"
  SIM_DIR="$WORKSPACE_DIR/sim"
  LOG_DIR="$WORKSPACE_DIR/sim/logs"
  OBJ_DIR="$WORKSPACE_DIR/sim/obj_dir"
else
  # v1.0 mode: argument is a bare module name
  MODULE="${ARG:-ALU}"
  GENERATED_DIR="$PLUGIN_ROOT/generated"
  SIM_DIR="$PLUGIN_ROOT/sim"
  LOG_DIR="$SIM_DIR/logs"
  OBJ_DIR="$SIM_DIR/obj_dir"
fi
```

Update waiver file resolution with the same fallback pattern as lint.sh:
```bash
if [ -f "$GENERATED_DIR/chisel-warnings.vlt" ]; then

WAIVER_ARGS=()
```
