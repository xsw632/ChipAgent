**Step A: Create ALU.scala**

Create `chisel-project/src/main/scala/chipagent/ALU.scala` with this exact implementation:

```scala
package chipagent

import chisel3._
import chisel3.util._

class ALU extends Module {
  val io = IO(new Bundle {
    val a      = Input(UInt(32.W))
    val b      = Input(UInt(32.W))
    val op     = Input(UInt(3.W))
    val result = Output(UInt(32.W))
    val zero   = Output(Bool())
  })

  // Default assignments (prevents latch inference)
  io.result := 0.U

  switch(io.op) {
    is(0.U) { io.result := io.a + io.b }                           // ADD
    is(1.U) { io.result := io.a - io.b }                           // SUB
    is(2.U) { io.result := io.a & io.b }                           // AND
    is(3.U) { io.result := io.a | io.b }                           // OR
    is(4.U) { io.result := io.a ^ io.b }                           // XOR
    is(5.U) { io.result := (io.a.asSInt < io.b.asSInt).asUInt }   // SLT (signed)
  }

  io.zero := io.result === 0.U
}
```

Key conventions enforced:
- `package chipagent` matches project convention
- `import chisel3.util._` required for `switch`/`is`
- Default `io.result := 0.U` before switch (prevents undriven wire)
- SLT uses `.asSInt` for signed comparison per RISC-V spec
- `Bool()` for zero flag, not `UInt(1.W)`

**Step B: Rewrite Generate.scala for dynamic module emission**

Rewrite `chisel-project/src/main/scala/chipagent/Generate.scala` to accept a `--module` argument:

```scala
package chipagent

import chisel3._
import chisel3.stage.ChiselStage

object Generate extends App {
  val targetDir = if (args.contains("--target-dir")) {
    val idx = args.indexOf("--target-dir")
    args(idx + 1)
  } else {
    "../generated"
  }

  val moduleName = if (args.contains("--module")) {
    val idx = args.indexOf("--module")
    args(idx + 1)
  } else {
    "TrivialModule"
  }

  val module: () => Module = moduleName match {
    case "TrivialModule" => () => new TrivialModule
    case "ALU"           => () => new ALU
    case other => throw new IllegalArgumentException(s"Unknown module: $other. Available: TrivialModule, ALU")
  }

  (new ChiselStage).emitVerilog(
    module(),
    Array("--target-dir", targetDir)
  )
}
```

Note: The match-statement approach is used here because the chisel-generator agent (from Plan 01) will instruct Claude to REWRITE Generate.scala entirely each time a new module is created. This file serves as the current known-good version. Future generated modules will replace this file's contents.

Important: Use `(new ChiselStage).emitVerilog(...)` -- NOT `emitSystemVerilogFile` (Chisel 3.6.1 API).
