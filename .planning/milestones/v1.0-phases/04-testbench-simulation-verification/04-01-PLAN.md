Port mapping (Verilog -> C++ testbench access):
  input  clock       -> dut->clock
  input  reset       -> dut->reset
  input  [31:0] io_a -> dut->io_a
  input  [31:0] io_b -> dut->io_b
  input  [2:0] io_op -> dut->io_op
  output [31:0] io_result -> dut->io_result
  output io_zero     -> dut->io_zero

Operation encoding:
  0 = ADD (io_a + io_b)
  1 = SUB (io_a - io_b)
  2 = AND (io_a & io_b)
  3 = OR  (io_a | io_b)
  4 = XOR (io_a ^ io_b)
  5 = SLT (signed(io_a) < signed(io_b) ? 1 : 0)
</interfaces>

  <action>
Create `sim/tb_ALU.cpp` -- a C++ testbench for Verilator simulation of the ALU module:

1. Include `"VALU.h"` and `"verilated.h"` and `<cstdio>`.

2. Define a `TestCase` struct with fields: `int op`, `uint32_t a`, `uint32_t b`, `uint32_t expected`, `const char* op_name`.

3. Define at least 12 test cases covering all 6 operations (minimum 2 per operation):
   - ADD: (5, 3, 8), (0xFFFFFFFF, 1, 0) -- overflow wrap
   - SUB: (10, 3, 7), (0, 1, 0xFFFFFFFF) -- underflow wrap
   - AND: (0xFF00FF00, 0x0F0F0F0F, 0x0F000F00), (0xAAAAAAAA, 0x55555555, 0x00000000)
   - OR:  (0xFF00, 0x00FF, 0xFFFF), (0xA0A0A0A0, 0x05050505, 0xA5A5A5A5)
   - XOR: (0xFF, 0xFF, 0x00), (0xAAAAAAAA, 0x55555555, 0xFFFFFFFF)
   - SLT: (1, 2, 1) -- 1 < 2 is true, (0xFFFFFFFF, 0, 1) -- -1 < 0 is true (signed)

4. In `main()`:
   - Create `VerilatedContext* ctx = new VerilatedContext;` and call `ctx->commandArgs(argc, argv);`
   - Create `VALU* dut = new VALU{ctx};`
   - Initialize: `dut->clock = 0; dut->reset = 0;`
   - Loop over test cases: set `dut->io_op`, `dut->io_a`, `dut->io_b`, call `dut->eval()`, read `dut->io_result`
   - Compare `got` to `expected`, count passes
   - Print each result in EXACT format: `[TEST %d] %s: a=%u b=%u | expect=%u got=%u | PASS` or `FAIL`
   - After loop, print final line in EXACT format: `RESULT: PASSED %d/%d tests` or `RESULT: FAILED %d/%d tests`
   - Call `dut->final(); delete dut; delete ctx;`
   - Return 0 if all passed, 1 otherwise

Create `scripts/simulate.sh` following the project script convention (see compile.sh and lint.sh for pattern):

1. `#!/usr/bin/env bash` with `set -euo pipefail`
2. `PLUGIN_ROOT="${CLAUDE_PLUGIN_ROOT:-$(cd "$(dirname "$0")/.." && pwd)}"`
3. Derive `GENERATED_DIR`, `SIM_DIR`, `LOG_DIR` from PLUGIN_ROOT
4. Accept module name as argument: `MODULE="${1:-ALU}"`
5. Verilate step: `verilator --cc "$GENERATED_DIR/$MODULE.v" --exe "$SIM_DIR/tb_$MODULE.cpp" --Mdir "$SIM_DIR/obj_dir" -CFLAGS "-std=c++17"` -- also pass the waiver file if it exists to suppress warnings during verilation
6. Build step: `make -C "$SIM_DIR/obj_dir" -f "V$MODULE.mk" -j$(nproc)`
7. Run step: `mkdir -p "$LOG_DIR"` then execute `"$SIM_DIR/obj_dir/V$MODULE"` and tee output to both stdout and `"$LOG_DIR/sim_result.log"`
8. Capture exit code from the simulation binary and exit with it
9. Print a summary line: `SIM PASSED` or `SIM FAILED` based on exit code

Update `.gitignore` to add `sim/obj_dir/` entry if not already present. The existing file already has `obj_dir/` at root level, but add `sim/obj_dir/` explicitly for clarity.
