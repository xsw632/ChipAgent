Create `scripts/lint.sh` following the pattern from 03-RESEARCH.md Pattern 1:

1. Use `PLUGIN_ROOT="${CLAUDE_PLUGIN_ROOT:-$(cd "$(dirname "$0")/.." && pwd)}"` (same as compile.sh).
2. Find all `.v` files in `$PLUGIN_ROOT/generated/` (maxdepth 1). Exit 1 with "LINT ERROR: No .v files found" if none exist.
3. Lint each `.v` file INDIVIDUALLY (not all at once -- avoids MULTITOP warning):

   - Run `verilator --lint-only -Wall -Wno-fatal` with waiver file, pipe through grep for `^%Warning`, append to `$PLUGIN_ROOT/generated/lint-warnings.log`.
   - Truncate lint-warnings.log at the start of the script (not per-file).
5. At the end, if lint-warnings.log is non-empty, print warning count and contents.
6. Exit 0 if LINT_PASS=true, exit 1 otherwise. Print "LINT PASSED: All files clean" or "LINT FAILED: Fix errors above and retry".
7. Make the script executable (chmod +x).

- `verilator_config` directive
- `lint_off -rule UNUSEDSIGNAL` for clock and reset in `*/generated/*`
- Include comments explaining WHY these warnings are suppressed (Chisel Module base class always emits clock/reset)

Important: Use `set -euo pipefail` at the top of lint.sh. Use `#!/usr/bin/env bash` shebang.
