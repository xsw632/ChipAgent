1. **MCP Server Foundation** — TypeScript MCP server with stdio transport, .mcp.json auto-discovery, and check_environment tool detecting ORFS/sky130hd/Docker
2. **sky130hd PDK Switch** — Complete nangate45 → sky130hd migration: detect-env.sh rewritten, 4 legacy scripts removed, migration stubs added
3. **Config Generation** — generate_config tool producing ORFS-compatible config.mk and constraint.sdc with sequential/combinational detection
4. **ORFS Stage Execution** — run_stage tool executing 6 ORFS make targets (synth/floorplan/place/cts/route/finish) with structured output
5. **Metric Extraction** — get_report tool parsing stage-specific metrics (cell count, area, WNS/TNS, DRC, power) from ORFS reports
6. **PnR Skill Rewrite** — /chip-agent:pnr orchestrates via 4 MCP tools with formatted PPA summary report
