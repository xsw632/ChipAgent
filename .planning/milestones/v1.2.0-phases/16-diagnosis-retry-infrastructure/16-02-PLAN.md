<objective>
Create the `clean_design` MCP tool, extend `generate_config` with optional tuning parameters, and register all new Phase 16 tools in the MCP server entry point.

Purpose: `clean_design` is a non-negotiable prerequisite for any retry logic -- ORFS make caches results by file timestamp, so changing config.mk parameters without cleaning causes retries to silently reuse stale results. The `generate_config` extension enables the Skill layer to produce config.mk files with placement density and timing-driven options needed for congestion/timing retry strategies. Registration wires everything into the running server.

Output: `mcp-server/tools/clean-design.ts`, extended `mcp-server/tools/generate-config.ts`, updated `mcp-server/index.ts`, and tests for both tools.
</objective>
