   - mcp__chipagent-backend__compare_runs

2. **Step 2 -- Generate Config:** After generating config, initialize tracking state:
   - current_params = { clock_period_ns, core_utilization: 40 } (defaults)
   - restart_from = "synth"
   - round = 1, max_rounds = 3

3. **Step 2.5 -- Clear QoR History:** Call compare_runs(action="clear", workspace_dir=...) to reset history for fresh run.

4. **Step 3 -- Replace entirely** with retry loop per 17-RESEARCH.md pseudocode:

   While round <= max_rounds:
   a. Run stages from restart_from through finish (using STAGE_ORDER slice)
   b. After each stage, call get_report. Display per-stage metrics (keep existing format).
   c. Determine pass/fail:
      - If any run_stage returns success=false: status="fail", record failed_stage and stderr
      - If all succeed: check finish report WNS and route DRC
      - pass = all stages succeed AND WNS >= 0 AND DRC == 0
   d. Collect metrics from finish get_report (wns, tns, area, total_w) and route get_report (violations). Use partial metrics if stage failed early.
   e. Call compare_runs(action="save") with: round, config (current_params), metrics, status, error_type (if fail)
   f. If pass: break with success message
   g. If round == max_rounds: break with "max retries exhausted" message
   h. Call diagnose_failure with:
      - workspace_dir, stage (failed stage or "finish" for silent timing), stderr (if any)
      - current_params: clock_period_ns and core_utilization from current_params
   i. If severity == "critical": break with message explaining not fixable by parameter adjustment
   j. Merge suggested_params into current_params (overwrite matching keys, keep others)
   k. Display: "Round {round} diagnosed: {error_type}. Adjusting: {changed params}. Restarting from {restart_from}."
   l. Call clean_design(workspace_dir=...)
   m. Call generate_config with module_name, verilog_path, workspace_dir, clock_port, and ALL current_params (clock_period_ns, core_utilization, plus any optional: place_density, gpl_timing_driven, gpl_routability_driven)
   n. Set restart_from = diagnosis.restart_from
   o. round += 1

   CRITICAL RULES for retry loop:
   - ALWAYS call clean_design before every retry, even for partial restart
   - Track current_params mutably -- each round builds on previous adjustments (no drift)
   - If severity is "critical" (synthesis_error, combinational timing_violation), exit immediately
   - Display clear round separator: "=== Retry Round {N}/{max_rounds} ==="

5. **Step 4 -- QoR Comparison and Recommendation:** Replace the current Step 4 with:
   a. Call compare_runs(action="load") to get all runs
   b. Format comparison table per 17-RESEARCH.md format:
      ```
      === QoR Comparison: <ModuleName> ===
      | Round | Clock (ns) | Utilization | Density | WNS (ns) | TNS (ns) | Area (um2) | Power (uW) | DRC | Status |
      ```
      Use "N/A" for missing metrics on failed runs.
   c. Call compare_runs(action="recommend") to get best run
   d. If best run exists: "Recommendation: Round {N} (clock={X}ns, WNS={Y}ns, area={Z}um2)"
   e. If no best run: "No passing run found. All rounds failed or had timing/DRC violations."

6. **Step 5 -- Format PPA Report:** Keep existing Step 4 content (pnr-report-formatter agent) but renumber to Step 5. Only run this if at least one passing round exists. Use the best run's metrics.

7. **Update Pipeline Stages table** at bottom to reflect new steps.

8. **Update Anti-Patterns** section: Add:
   - DO NOT skip clean_design between retries -- ORFS caches all stages
   - DO NOT retry when severity is "critical" -- synthesis errors and combinational timing violations are not parameter-fixable
   - DO NOT reset current_params to original values between rounds -- build on previous adjustments
