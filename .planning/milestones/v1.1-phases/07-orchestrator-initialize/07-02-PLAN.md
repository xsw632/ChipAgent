**1. Create `scripts/detect-env.sh`** -- environment detection script.

CRITICAL: Do NOT use `set -e`. Missing tools must produce `"installed": false` in the output, not crash the script.

Structure:
```bash
#!/usr/bin/env bash
# Do NOT use set -e -- missing tools produce "installed: false", not crashes

PLUGIN_ROOT="${CLAUDE_PLUGIN_ROOT:-$(cd "$(dirname "$0")/.." && pwd)}"
OUTPUT_DIR="$PLUGIN_ROOT/.chipagent"
OUTPUT_FILE="$OUTPUT_DIR/env.json"

mkdir -p "$OUTPUT_DIR"
```

Create a `detect_tool` function that:
- Takes: tool_name, command_name, version_command, version_regex
- Uses `command -v "$command_name" 2>/dev/null` to check existence
- If found: runs the version command, extracts version with grep -oP (or grep -oE for portability), records path
- If not found: sets installed=false, version="", path=""
- Returns a JSON fragment string via printf

Call detect_tool for each of the 6 tools:
- java: `java -version 2>&1 | head -1`, regex to extract version number (format: "17.0.18" or "1.8.0_382")
- sbt: `sbt --batch --version 2>&1 | tail -1`, regex for version number. Use `--batch` to avoid interactive mode.
- scala: `scala -version 2>&1 | head -1`, regex for version number
- verilator: `verilator --version 2>&1 | head -1`, regex for version number (format: "Verilator 5.008")
- make: `make --version 2>&1 | head -1`, regex for version number
- gpp: `g++ --version 2>&1 | head -1`, regex for version number

Compute capability flags from the installed booleans:
- can_compile: java AND sbt both installed
- can_lint: verilator installed
- can_simulate: verilator AND make AND gpp all installed

Assemble the final JSON. Prefer `jq` if available for correct formatting. Fallback to a heredoc with variable interpolation if `jq` is not installed.

Write the JSON to `$OUTPUT_FILE`.

Print a summary to stdout for the skill to present to the user:
```
=== ChipAgent Environment Detection ===
Java:      [OK] 17.0.18    OR    [MISSING]
sbt:       [OK] 1.10.7     OR    [MISSING]
...
Capabilities:
  Compile:  YES/NO
  Lint:     YES/NO
  Simulate: YES/NO

Written: .chipagent/env.json
```

Make the script executable: `chmod +x scripts/detect-env.sh`
