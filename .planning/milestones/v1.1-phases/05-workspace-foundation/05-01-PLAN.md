Modify `scripts/compile.sh` to accept an optional first positional argument as a workspace path. When present, derive all output paths from it. When absent, keep v1.0 flat behavior unchanged.

**compile.sh changes:**

1. After the existing PLUGIN_ROOT resolution block (lines 1-14), replace the hardcoded `OUTPUT_DIR="$PLUGIN_ROOT/generated"` with workspace-aware path resolution:

```bash
# --- Workspace-aware path resolution ---
WORKSPACE_ARG="${1:-}"
if [ -n "$WORKSPACE_ARG" ]; then
  case "$WORKSPACE_ARG" in
    /*) WORKSPACE_DIR="$WORKSPACE_ARG" ;;
    *)  WORKSPACE_DIR="$PLUGIN_ROOT/$WORKSPACE_ARG" ;;
  esac
  MODULE=$(basename "$WORKSPACE_DIR")
  OUTPUT_DIR="$WORKSPACE_DIR/generated"
else
  OUTPUT_DIR="$PLUGIN_ROOT/generated"
  MODULE=""
fi
```

2. Keep the existing `mkdir -p "$OUTPUT_DIR"`, `LOG`, `trap`, `cd`, timeout detection unchanged.

3. Replace the single sbt invocation with a conditional:
   - If `MODULE` is non-empty: `$TIMEOUT_CMD sbt --batch "runMain chipagent.Generate --module $MODULE --target-dir $OUTPUT_DIR" > "$LOG" 2>&1 || EXIT_CODE=$?`
   - If `MODULE` is empty: keep existing command `$TIMEOUT_CMD sbt --batch "runMain chipagent.Generate --target-dir $OUTPUT_DIR" > "$LOG" 2>&1 || EXIT_CODE=$?`

4. The success/error reporting section remains identical (it already uses `$OUTPUT_DIR`).

IMPORTANT: All paths passed to sbt `--target-dir` MUST be absolute. The workspace resolution (case statement) ensures this. Do NOT pass relative paths -- sbt runs from `chisel-project/` so relative paths resolve incorrectly (Pitfall 1 from research).

**Also create workspace subdirectories:** Before the sbt call, if in workspace mode, run `mkdir -p "$WORKSPACE_DIR/generated" "$WORKSPACE_DIR/sim/logs"` to create the full workspace tree (WKSP-01 requires spec, generated, and sim dirs exist).

1. **Backward compatibility (flat mode):** Run `scripts/compile.sh` with no arguments. Verify exit code 0 and that `generated/TrivialModule.v` exists (this is the default module).

2. **Workspace mode:** Run `scripts/compile.sh workspace/TrivialModule`. Verify:

   - `workspace/TrivialModule/generated/TrivialModule.v` exists
   - `workspace/TrivialModule/sim/logs/` directory exists (created by mkdir -p in compile.sh)

3. **Gitignore coverage:** Run `grep -q 'workspace/' .gitignore` and verify it matches.

4. **Git status clean:** After workspace compilation, run `git status --porcelain workspace/` and verify it outputs nothing (gitignore is working).

Script structure:
```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
PLUGIN_ROOT="$(cd "$SCRIPT_DIR/.." && pwd)"
PASS=0; FAIL=0; TOTAL=0

check() {
  TOTAL=$((TOTAL + 1))
  if eval "$1" >/dev/null 2>&1; then
    echo "  PASS: $2"
    PASS=$((PASS + 1))
  else
    echo "  FAIL: $2"
    FAIL=$((FAIL + 1))
  fi
}

# Clean up workspace from prior runs
rm -rf "$PLUGIN_ROOT/workspace/TrivialModule"

echo "=== Phase 5: Workspace Foundation ==="

echo ""
echo "--- Test 1: Backward compatibility (flat compile) ---"
"$SCRIPT_DIR/compile.sh"
check 'test -f "$PLUGIN_ROOT/generated/TrivialModule.v"' "Flat mode: TrivialModule.v exists in generated/"

echo ""
echo "--- Test 2: Workspace mode compile ---"
"$SCRIPT_DIR/compile.sh" workspace/TrivialModule
check 'test -f "$PLUGIN_ROOT/workspace/TrivialModule/generated/TrivialModule.v"' "Workspace mode: TrivialModule.v in workspace/TrivialModule/generated/"
check 'test -d "$PLUGIN_ROOT/workspace/TrivialModule/sim/logs"' "Workspace mode: sim/logs/ dir created"
check 'test -d "$PLUGIN_ROOT/workspace/TrivialModule/generated"' "Workspace mode: generated/ dir created"

echo ""
echo "--- Test 3: Gitignore coverage ---"
check 'grep -q "workspace/" "$PLUGIN_ROOT/.gitignore"' "Gitignore: workspace/ pattern present"
check 'test -z "$(git -C "$PLUGIN_ROOT" status --porcelain workspace/ 2>/dev/null)"' "Gitignore: workspace/ produces no untracked files"

echo ""
echo "=== Results: $PASS/$TOTAL passed, $FAIL failed ==="
[ "$FAIL" -eq 0 ] && echo "ALL TESTS PASSED" || echo "SOME TESTS FAILED"
exit "$FAIL"
```

Make the script executable: `chmod +x scripts/test-phase5.sh`.
