  <name>Task 1: Create synth.tcl Yosys synthesis recipe</name>
  <files>scripts/synth.tcl</files>
  <action>
Create `scripts/synth.tcl` -- the standalone Yosys Tcl script for nangate45 ASIC synthesis.

The script reads all paths from environment variables (set by synth.sh):
- `DESIGN_NAME` -- module name (e.g., ALU)
- `VERILOG_FILE` -- path to input Verilog
- `LIB_FILE` -- path to nangate45 liberty (.lib)
- `OUTPUT_DIR` -- path to workspace/pnr/
- `REPORTS_DIR` -- path to workspace/pnr/reports/

Exact Tcl command sequence (verified on Yosys 0.53+26 per RESEARCH.md):

```tcl
# synth.tcl - Yosys ASIC synthesis for nangate45
# All paths from environment variables set by synth.sh

read_liberty -lib $::env(LIB_FILE)
read_verilog -DSYNTHESIS $::env(VERILOG_FILE)
synth -top $::env(DESIGN_NAME) -flatten
dfflibmap -liberty $::env(LIB_FILE)
abc -liberty $::env(LIB_FILE)
setundef -zero
splitnets
opt_clean -purge
tee -o $::env(REPORTS_DIR)/synth_check.txt check
tee -o $::env(REPORTS_DIR)/synth_stat.txt stat -liberty $::env(LIB_FILE)
write_verilog -noattr -noexpr -nohex -nodec $::env(OUTPUT_DIR)/$::env(DESIGN_NAME).synth.v
```

Critical ordering rules (from RESEARCH.md anti-patterns):
- `dfflibmap` BEFORE `abc` (dfflibmap maps flip-flops; abc maps combinational only)
- `-DSYNTHESIS` on read_verilog (excludes Chisel RANDOMIZE init blocks)
- `synth -top <name> -flatten` (always specify -top, always flatten for small Chisel modules)
- `write_verilog -noattr -noexpr -nohex -nodec` (structural Verilog for OpenROAD compatibility)
- `stat -liberty` (NOT bare `stat`) to get area numbers in the report
- Do NOT use `check -assert` (benign warnings on output ports after abc mapping)

Add a comment header explaining purpose and environment variable contract.

<task type="auto">
  <name>Task 2: Create synth.sh bash wrapper with pre-flight checks and end-to-end verification</name>
  <files>scripts/synth.sh</files>
  <action>
Create `scripts/synth.sh` -- the bash wrapper that orchestrates synthesis. Follow the compile.sh pattern for path resolution and error handling.

**Script structure:**

1. **Shebang and strict mode:** `#!/usr/bin/env bash` + `set -euo pipefail`

2. **Source _common.sh:** Same pattern as compile.sh -- source, check _COMMON_INIT_FAILED, print error and exit 1 if failed.

3. **Argument parsing and path resolution:** Follow compile.sh's three-mode pattern:
   - Bare name (e.g., `ALU`) -> `MyDesign/ALU/`
   - `MyDesign/ALU` explicit path
   - `workspace/ALU` backward compat
   Extract MODULE name via `basename`. Resolve VERILOG_PATH to `workspace/generated/<Module>.v`. Exit with usage message if no argument given.

4. **Verify Verilog exists:** Check `$VERILOG_PATH` file exists. Exit with clear error if not (module not yet compiled).

5. **Extract module name from Verilog:** Use the same pattern as generate_sdc.sh:
   ```bash
   MODULE_NAME=$(grep -m1 '^module ' "$VERILOG_PATH" | sed 's/^module \([A-Za-z_][A-Za-z0-9_]*\).*/\1/')
   ```

6. **Pre-flight PDK validation:** Call `bash "$PLUGIN_ROOT/scripts/validate-pdk.sh"` (exits on failure).

7. **Generate SDC:** Call `bash "$PLUGIN_ROOT/scripts/generate_sdc.sh" "$MODULE"` (creates workspace/pnr/constraint.sdc).

8. **Resolve PDK path:** Read from `NANGATE45_DIR` env var, fall back to `jq -r '.pdk.nangate45.path // empty' "$PLUGIN_ROOT/.chipagent/env.json"`. Exit if empty.

9. **Set environment variables for synth.tcl:**
   - `DESIGN_NAME="$MODULE_NAME"`
   - `VERILOG_FILE="$VERILOG_PATH"`
   - `LIB_FILE="$PDK_DIR/lib/NangateOpenCellLibrary_typical.lib"`
   - `OUTPUT_DIR="$PNR_DIR"` (where PNR_DIR is the workspace/pnr/ path)
   - `REPORTS_DIR="$PNR_DIR/reports"`
   - `SDC_FILE="$PNR_DIR/constraint.sdc"`
   Export all of these.

10. **Create output directories:** `mkdir -p "$PNR_DIR/reports"`

11. **Run Yosys synthesis:** `yosys -c "$PLUGIN_ROOT/scripts/synth.tcl"` with stdout/stderr captured to a log file. Handle exit code -- if non-zero, print the log and exit 1.

12. **Verify output netlist:** Check file exists at `$PNR_DIR/${MODULE_NAME}.synth.v`. If missing, print error + log and exit 1.

13. **Print summary:** Extract gate count and area from the stat report:
    ```bash
    GATE_COUNT=$(grep 'Number of cells:' "$PNR_DIR/reports/synth_stat.txt" | awk '{print $NF}')
    AREA=$(grep 'Chip area for module' "$PNR_DIR/reports/synth_stat.txt" | grep -oE '[0-9]+\.[0-9]+' | head -1)
    echo "Synthesis complete:"
    echo "  Module:  $MODULE_NAME"
    echo "  Cells:   $GATE_COUNT"
    echo "  Area:    ${AREA}um2"
    echo "  Netlist: $PNR_DIR/${MODULE_NAME}.synth.v"
    echo "  Report:  $PNR_DIR/reports/synth_stat.txt"
    ```

14. **Make executable:** `chmod +x scripts/synth.sh`

**After creating the script, run end-to-end verification:**

a. Run `bash scripts/synth.sh ALU` from the project root -- must produce ALU.synth.v netlist and synth_stat.txt
b. Run `bash scripts/synth.sh Counter8` from the project root -- must produce Counter8.synth.v netlist and synth_stat.txt
c. Verify both stat reports contain "Number of cells:" and "Chip area for module"
d. Verify both netlists contain nangate45 cell instances (grep for standard cell names like AND2_X1, INV_X1, DFF_X1, etc.)
e. Run OpenROAD parse check on at least one netlist:

   ```bash
   read_liberty $LIB_FILE
   read_lef $LEF_FILE
   read_verilog $NETLIST
   link_design $MODULE_NAME
   ORCMD
   ```
   (OpenROAD must exit 0 with "link_design" success)

If any verification step fails, diagnose and fix before committing.
