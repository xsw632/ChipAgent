  <name>Task 1: Create pnr.tcl OpenROAD recipe and def2gds.py KLayout merge script</name>

  <action>
Create two scripts that are standalone OpenROAD and KLayout recipes respectively.

**scripts/pnr.tcl** -- OpenROAD Tcl PnR recipe for nangate45. All paths come from environment variables set by pnr.sh. The complete verified flow:

1. LOAD section: `read_liberty`, `read_lef` (tech + cell), `read_verilog`, `link_design`, `read_sdc` -- all reading from `$::env(...)` variables.

2. FLOORPLAN section: Count cells with `[llength [get_cells -hier *]]`. If fewer than 100 cells, use explicit minimum die area `"0 0 70 70"` with core area `"5 5 65 65"` and site `FreePDK45_38x28_10R_NP_162NW_34O` (prevents PDN failure on small modules -- PDN-0185 metal4 stripe pitch issue). Otherwise use `initialize_floorplan -utilization 30 -aspect_ratio 1 -core_space 5 -site FreePDK45_38x28_10R_NP_162NW_34O`. Then source `$::env(PDK_DIR)/make_tracks.tcl` and `$::env(PDK_DIR)/grid_strategy-M1-M4-M7.tcl`, run `pdngen`, insert tapcells with `TAPCELL_X1` at distance 120, place pins on metal5 (horizontal) and metal6 (vertical).

3. PLACEMENT section: `global_placement -density 0.3`, `detailed_placement`, `check_placement -verbose`.

4. RC + CTS section: Source `$::env(PDK_DIR)/setRC.tcl`, `estimate_parasitics -placement`. Then conditionally (only if `$::env(IS_SEQUENTIAL)` is truthy): `repair_clock_inverters`, `clock_tree_synthesis -sink_clustering_enable`, `detailed_placement`, `estimate_parasitics -placement`, `repair_timing`, `detailed_placement`.

5. ROUTING section: Layer adjustments -- `metal2-metal3` at 0.5, `metal4-metal10` at 0.25. Set routing layers `metal2-metal10` for signal. Conditionally set clock routing `metal4-metal10` only if IS_SEQUENTIAL. `global_route`, `set_propagated_clock [all_clocks]`, `detailed_route -output_drc $::env(REPORTS_DIR)/drc.rpt -verbose 1`.

6. POST-ROUTE: `filler_placement "FILLCELL_X1 FILLCELL_X2 FILLCELL_X4 FILLCELL_X8 FILLCELL_X16 FILLCELL_X32"`, `check_placement`.

7. EXTRACTION: `define_process_corner -ext_model_index 0 X`, `extract_parasitics -ext_model_file $::env(RCX_RULES)`.

8. REPORTS section: Print marker-delimited report sections (`=== TIMING_REPORT_START ===` / `=== TIMING_REPORT_END ===` etc.) around `report_checks -path_delay max -format full_clock_expanded`, `report_power`, `report_design_area`. Extract WNS/TNS via `sta::format_time [sta::worst_slack_cmd max] 3` and `sta::format_time [sta::total_negative_slack_cmd max] 3`, print as `PNR_WNS:` and `PNR_TNS:` lines.

9. OUTPUT: `write_def $::env(OUTPUT_DIR)/$::env(DESIGN_NAME).routed.def`, print `PNR_COMPLETE`.

CRITICAL: Do NOT use `report_checks -file` (does not exist in OpenROAD 26Q1). Do NOT use `redirect` command (not available). Reports captured via `-log` with marker extraction by pnr.sh. Do NOT run `repair_timing` before CTS for sequential modules.

Environment variables expected: DESIGN_NAME, NETLIST, SDC_FILE, LIB_FILE, TECH_LEF, CELL_LEF, PDK_DIR, OUTPUT_DIR, REPORTS_DIR, IS_SEQUENTIAL, RCX_RULES.

**scripts/def2gds.py** -- KLayout Python script for DEF-to-GDS merge. Invoked via `klayout -zz -r` with `-rd` parameter passing.

1. Read variables from KLayout `-rd` globals: design_name, in_def, tech_lef, cell_lef, in_gds, out_file.
2. Create `pya.LoadLayoutOptions()`, set `layoutOptions.lefdef_config.lef_files = [tech_lef, cell_lef]`.
3. Create `pya.Layout()`, read DEF with layout options.
4. Get top cell index from `main_layout.cell(design_name).cell_index()`.
5. Clear orphan cells (not top cell and not VIA_ prefixed) via `i.clear()`.
6. Read standard cell GDS with `main_layout.read(in_gds)`.
7. Create clean output layout, copy tree from top cell.
8. Verify no empty cells (print ERROR for each, count errors).
9. Write output GDS, print file path and size, `sys.exit(errors)`.

CRITICAL: Do NOT use `.lyt` tech file for DEF reading (produces dummy macros). Use LEF files via `layoutOptions.lefdef_config.lef_files` instead.

  <name>Task 2: Create pnr.sh bash wrapper with end-to-end verification on ALU and Counter8</name>
  <files>scripts/pnr.sh</files>
  <action>
Create `scripts/pnr.sh` following the established pattern from `scripts/synth.sh`. This bash wrapper orchestrates the full PnR + GDS pipeline.

**Structure (follow synth.sh pattern exactly):**

1. Shebang + `set -euo pipefail` + source `_common.sh` + check `_COMMON_INIT_FAILED`.

2. Argument parsing: Same three-mode resolution as synth.sh (bare name, MyDesign/Module, workspace/Module). Usage message on no args: `"Usage: pnr.sh <ModuleName>"` with examples.

3. Path resolution:
   - `VERILOG_PATH="$MODULE_DIR/workspace/generated/${MODULE}.v"`
   - `PNR_DIR="$MODULE_DIR/workspace/pnr"`
   - `REPORTS_DIR="$PNR_DIR/reports"`
   - `NETLIST="$PNR_DIR/${MODULE}.synth.v"` (from Phase 10 synth.sh output; use MODULE not MODULE_NAME here since MODULE_NAME comes from Verilog parsing later)

4. Pre-flight checks:
   - Verify synthesized netlist exists at `$PNR_DIR/<module>.synth.v`. If missing, print error directing to run `scripts/synth.sh <Module>` first.
   - Verify SDC exists at `$PNR_DIR/constraint.sdc`. If missing, print error directing to run `scripts/synth.sh <Module>` first (synth.sh calls generate_sdc.sh).
   - Run `validate-pdk.sh` (exit on failure).

5. Extract module name from Verilog: `grep -m1 '^module '` on `$VERILOG_PATH` (same pattern as synth.sh). Set `MODULE_NAME` from this. Then update NETLIST path to use MODULE_NAME: `NETLIST="$PNR_DIR/${MODULE_NAME}.synth.v"`. Verify this file exists.

6. PDK path resolution: Same pattern as synth.sh -- `NANGATE45_DIR` env var > env.json via jq > error.

7. Sequential detection: `grep -q 'always @(posedge' "$VERILOG_PATH"` -- if found, `IS_SEQUENTIAL=1`, else `IS_SEQUENTIAL=0`. Print detection result.

8. Export environment variables for pnr.tcl:
   - DESIGN_NAME, NETLIST, SDC_FILE (= $PNR_DIR/constraint.sdc), LIB_FILE, TECH_LEF, CELL_LEF, PDK_DIR, OUTPUT_DIR (= $PNR_DIR), REPORTS_DIR, IS_SEQUENTIAL, RCX_RULES (= $PDK_DIR/rcx_patterns.rules)

9. Create output directories: `mkdir -p "$REPORTS_DIR"`

10. Run OpenROAD:
    - Create temp log file (same pattern as synth.sh)
    - `openroad -no_init -exit -log "$LOG_FILE" "$PLUGIN_ROOT/scripts/pnr.tcl"`
    - On failure: print error + tail of log + exit 1
    - On success: verify `PNR_COMPLETE` marker in log

11. Verify routed DEF exists: `$PNR_DIR/${MODULE_NAME}.routed.def`. Error if missing.

12. Extract reports from log using sed with markers:
    - timing.rpt from TIMING_REPORT_START/END
    - power.rpt from POWER_REPORT_START/END
    - area.rpt from AREA_REPORT_START/END
    - WNS from `grep '^PNR_WNS:' "$LOG_FILE" | awk '{print $2}'`
    - TNS from `grep '^PNR_TNS:' "$LOG_FILE" | awk '{print $2}'`

13. Run KLayout GDS export:
    ```
    klayout -zz \
      -rd design_name="$MODULE_NAME" \
      -rd in_def="$PNR_DIR/$MODULE_NAME.routed.def" \
      -rd tech_lef="$TECH_LEF" \
      -rd cell_lef="$CELL_LEF" \
      -rd in_gds="$PDK_DIR/gds/NangateOpenCellLibrary.gds" \
      -rd out_file="$PNR_DIR/$MODULE_NAME.gds" \
      -r "$PLUGIN_ROOT/scripts/def2gds.py"
    ```
    On failure: print error + exit 1.

14. Verify GDS exists and is non-empty. Error if missing or zero-size.

15. Print summary: Module name, WNS, TNS, timing status (MET/VIOLATED based on WNS >= 0), area, power total, DEF path, GDS path, reports directory.

16. Clean up temp log on exit (trap pattern from synth.sh).

Make the script executable: `chmod +x scripts/pnr.sh`.
